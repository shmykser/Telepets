# 🚀 Скрипты запуска Telepets

Эта папка содержит скрипты для удобного запуска и тестирования проекта.

## 📁 Файлы

### 🤖 `run_bot.py`
Запускает только Telegram бота
```bash
python scripts/run_bot.py
```

### 🌐 `run_webapp.py`
Запускает только Web App
```bash
python scripts/run_webapp.py
```

### ⭐ `run_all.py` (Рекомендуется)
Запускает и бота, и Web App одновременно
```bash
python scripts/run_all.py
```

## 🎯 Возможности

- ✅ **Автоматическое завершение** старых процессов
- ✅ **Красивые статусы** запуска
- ✅ **Обработка Ctrl+C** для корректного завершения
- ✅ **Правильные пути** к файлам проекта
- ✅ **Многопоточность** для одновременного запуска

## 🚀 Быстрый старт

1. **Запустите все сервисы:**
   ```bash
   python scripts/run_all.py
   ```

2. **Тестируйте в Telegram:**
   - `/start` - регистрация и информация
   - `/egg` - информация о яйце

3. **Откройте Web App:**
   - `http://localhost:5000` в браузере

## ⚠️ Примечания

- Скрипты автоматически завершают конфликтующие процессы
- Web App работает на `http://localhost:5000`
- Для Telegram Web App нужен HTTPS (ngrok/localhost)
- База данных создается автоматически в `telepets.db`
