🥚 Telepets API Documentation

Документация API для Telegram WebApp игры по инкубации виртуальных яиц

📋 Обзор API

Telepets API предоставляет эндпоинты для управления состоянием виртуальных яиц в Telegram WebApp. API поддерживает операции получения данных, нагрева, сброса состояния и получения обновлений в реальном времени.

GET /api/egg/{user_id}

Получение текущего состояния яйца пользователя

GET /api/egg/{user_id}/updates

Server-Sent Events для обновлений в реальном времени

POST /api/egg/{user_id}/warm

Нагрев яйца при выполнении свайпа

POST /api/egg/{user_id}/fix_egg

Сброс яйца к начальному состоянию

🛠️ Настройки для отладки

  • Локальный сервер: http://localhost:5000
  • Тестовый user_id: 273065571
  • CORS: Настроен для локальной разработки
  • Формат данных: JSON

🔍 Примеры использования

Попробуйте следующие запросы для тестирования API:

  • GET /api/egg/273065571 - получить данные тестового яйца
  • POST /api/egg/273065571/warm - нагреть тестовое яйцо
  • POST /api/egg/273065571/fix_egg - сбросить тестовое яйцо
