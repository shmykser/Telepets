# 🥚 Telepets API - Swagger Документация

Этот каталог содержит Swagger/OpenAPI документацию для API игры Telepets - виртуальной инкубации яиц в Telegram WebApp.

## 📁 Содержимое каталога

```
api-docs/
├── telepets-api.yaml     # OpenAPI 3.0 спецификация
├── swagger-ui.html       # Веб-интерфейс Swagger UI
├── swagger_server.py     # Отдельный сервер для документации
└── README.md            # Этот файл
```

## 🚀 Быстрый старт

### 1. Запуск отдельного сервера документации

```bash
# Переход в каталог с документацией
cd api-docs

# Запуск на порту 8080 (по умолчанию)
python swagger_server.py

# Запуск на другом порту
python swagger_server.py --port 9000

# Запуск без автооткрытия браузера
python swagger_server.py --no-browser
```

### 2. Открытие в браузере

После запуска сервера документация будет доступна по адресам:
- **Swagger UI**: http://localhost:8080/swagger-ui.html
- **OpenAPI спецификация**: http://localhost:8080/telepets-api.yaml

## 🔧 Использование для отладки

### Перед тестированием API

1. **Запустите основной API сервер** (в отдельном терминале):
   ```bash
   # Из корневой директории проекта
   python run_webapp.py
   # или
   python src/webapp.py
   ```

2. **Запустите сервер документации** (в другом терминале):
   ```bash
   cd api-docs
   python swagger_server.py
   ```

### Тестирование эндпоинтов

В Swagger UI вы можете протестировать все доступные эндпоинты:

#### 📥 GET запросы
- `GET /api/egg/273065571` - получить данные тестового яйца
- `GET /api/egg/273065571/updates?force=1` - получить обновления

#### 📤 POST запросы  
- `POST /api/egg/273065571/warm` - нагреть яйцо
- `POST /api/egg/273065571/fix_egg` - сбросить яйцо

### Тестирование через curl

```bash
# Получить данные яйца
curl http://localhost:5000/api/egg/273065571

# Нагреть яйцо
curl -X POST http://localhost:5000/api/egg/273065571/warm \
     -H "Content-Type: application/json"

# Сбросить яйцо
curl -X POST http://localhost:5000/api/egg/273065571/fix_egg \
     -H "Content-Type: application/json"

# Server-Sent Events (в отдельном терминале)
curl -N http://localhost:5000/api/egg/273065571/updates
```

## 📋 Описание API эндпоинтов

### 🥚 Управление яйцами

| Метод | Эндпоинт | Описание |
|-------|----------|-----------|
| `GET` | `/api/egg/{user_id}` | Получение данных яйца |
| `POST` | `/api/egg/{user_id}/warm` | Нагрев яйца при свайпе |
| `POST` | `/api/egg/{user_id}/fix_egg` | Сброс к начальному состоянию |

### 📡 Реальное время

| Метод | Эндпоинт | Описание |
|-------|----------|-----------|
| `GET` | `/api/egg/{user_id}/updates` | Server-Sent Events поток |

## 🔍 Структура данных

### EggData (ответ GET /api/egg/{user_id})
```json
{
  "user_id": 273065571,
  "temperature": 20.5,
  "progress": 45.2,
  "time_remaining": 98750.5,
  "status": "incubating",
  "last_updated": "2024-01-15T14:30:00Z",
  "formatted_time_remaining": "1:03:25:30",
  "message": "🌡️ Температура низкая. Трите яйцо для нагрева."
}
```

### WarmResponse (ответ POST /api/egg/{user_id}/warm)
```json
{
  "temperature": 21.5,
  "status": "warmed",
  "message": "Яйцо нагрето!"
}
```

### ResetResponse (ответ POST /api/egg/{user_id}/fix_egg)
```json
{
  "success": true,
  "message": "Яйцо сброшено к начальному состоянию"
}
```

## ⚠️ Важные замечания

### Валидация user_id
- Должен быть положительным целым числом
- Максимальное значение: 9223372036854775807 (int64)
- Тестовый ID для отладки: **273065571**

### CORS
- Настроен для локальной разработки
- Все заголовки Access-Control-* настроены

### Статусы яйца
- `incubating` - процесс инкубации
- `hatched` - вылупилось
- `dead` - погибло от экстремальных температур

### Критические температуры
- **Смертельно низкая**: ≤ 18°C
- **Критически низкая**: < 28°C (таймер останавливается)
- **Нормальная**: 28-41°C
- **Критически высокая**: > 41°C (таймер останавливается) 
- **Смертельно высокая**: ≥ 44°C
