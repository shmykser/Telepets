# Настройки Telepets

Этот файл содержит подробные инструкции по настройке параметров для тестирования и разработки.

## Структура настроек

### Frontend настройки (`static/js/settings.js`)

#### Настройки свайпов и взаимодействия
- `SWIPE_THRESHOLD_PERCENT` - Размер свайпа в процентах от ширины яйца (50% = 100px)
- `SWIPES_PER_DEGREE` - Количество свайпов для нагрева на 1 градус (50)
- `SWIPE_RESET_TIME` - Время сброса счетчика свайпов в миллисекундах (3000)
- `PROGRESS_DECAY_TIME` - Скорость уменьшения прогресса свайпов в миллисекундах (400)

#### Настройки температуры
- `CRITICAL_LOW_TEMP` - Критически низкая температура, останавливающая таймер (28°C)
- `CRITICAL_HIGH_TEMP` - Критически высокая температура, останавливающая таймер (41°C)
- `DEAD_LOW_TEMP` - Смертельная низкая температура (18°C)
- `DEAD_HIGH_TEMP` - Смертельная высокая температура (44°C)
- `NORMAL_TEMP_MIN` - Минимальная нормальная температура (28°C)
- `NORMAL_TEMP_MAX` - Максимальная нормальная температура (41°C)

#### Настройки времени
- `INCUBATION_TIME_HOURS` - Время инкубации в часах (72)
- `COOLING_INTERVAL_SECONDS` - Время остывания яйца в секундах (60)
- `DATA_UPDATE_INTERVAL` - Интервал обновления данных с сервера в миллисекундах (10000)
- `TIMER_UPDATE_INTERVAL` - Интервал обновления таймера в миллисекундах (1000)

#### Настройки анимаций
- `WARMING_ANIMATION_DURATION` - Длительность анимации нагрева (500мс)
- `RUBBING_ANIMATION_DURATION` - Длительность анимации трения (300мс)
- `TEMP_INCREASE_ANIMATION_DURATION` - Длительность анимации +1°C (1000мс)

#### Настройки тестирования
- `TEST_USER_ID` - Тестовый User ID (273065571)
- `DEBUG_MODE` - Режим отладки (true)
- `FAST_MODE` - Быстрый режим для тестирования (false)
- `FAST_MODE_MULTIPLIER` - Множитель времени в быстром режиме (0.1 = 10%)

### Backend настройки (`settings.py`)

#### Настройки времени инкубации
- `INCUBATION_TIME_SECONDS` - Время инкубации в секундах (259200 = 72 часа)
- `FAST_MODE` - Быстрый режим для тестирования (False)
- `FAST_MODE_MULTIPLIER` - Множитель времени в быстром режиме (0.1)

#### Настройки температуры
- `CRITICAL_LOW_TEMP` - Критически низкая температура (28°C)
- `CRITICAL_HIGH_TEMP` - Критически высокая температура (41°C)
- `DEAD_LOW_TEMP` - Смертельная низкая температура (18°C)
- `DEAD_HIGH_TEMP` - Смертельная высокая температура (44°C)
- `MAX_TEMP` - Максимальная температура нагрева (50°C)
- `MIN_TEMP` - Минимальная температура (15°C)

#### Настройки охлаждения
- `COOLING_INTERVAL_SECONDS` - Интервал охлаждения яйца в секундах (60)
- `COOLING_DEGREES_PER_INTERVAL` - Количество градусов остывания за интервал (1)

#### Настройки нагрева
- `WARMING_DEGREES_PER_RUB` - Количество градусов нагрева за трение (1)

#### Настройки базы данных
- `DATABASE_PATH` - Путь к файлу базы данных ('telepets.db')

#### Настройки логирования
- `LOG_LEVEL` - Уровень логирования ('INFO')
- `DEBUG_MODE` - Режим отладки (True)

#### Настройки тестирования
- `TEST_USER_ID` - Тестовый User ID (273065571)
- `TEST_MODE` - Режим тестирования (True)
- `AUTO_CREATE_TEST_EGG` - Автоматическое создание тестового яйца (False)

## Быстрое тестирование

### Для ускорения тестирования измените следующие параметры:

#### В `static/js/settings.js`:
```javascript
// Быстрый режим
FAST_MODE = true;
FAST_MODE_MULTIPLIER = 0.1; // 10% от обычного времени

// Легче свайпать
SWIPE_THRESHOLD_PERCENT = 20; // 20% вместо 50%
SWIPES_PER_DEGREE = 10;       // 10 свайпов вместо 50
PROGRESS_DECAY_TIME = 1000;    // 1 секунда вместо 0.4

// Быстрее обновления
DATA_UPDATE_INTERVAL = 5000;   // 5 секунд вместо 10
```

#### В `settings.py`:
```python
# Быстрый режим
FAST_MODE = True
FAST_MODE_MULTIPLIER = 0.1

# Быстрое охлаждение
COOLING_INTERVAL_SECONDS = 10  # 10 секунд вместо 60

# Автоматическое создание тестового яйца
AUTO_CREATE_TEST_EGG = True
```

### Запуск тестирования

1. Запустите скрипт для просмотра текущих настроек:
   ```bash
   python scripts/test_settings.py
   ```

2. Измените настройки в файлах `settings.py` и `static/js/settings.js`

3. Перезапустите приложение:
   ```bash
   python webapp.py
   ```

